## Contributing to frameworks-mini-project

Thanks for wanting to help — this is intentionally tiny and casual.

Quick checklist

- Fork the repo.
- Add your mini-project files in a new folder under the repo root (e.g., `my-cool-demo/`). Keep it small and self-contained.
- Include an `index.html` plus any lightweight `styles.css` or JS files. Avoid heavy build setups.
- Add a short `README.md` inside your project folder with a 1–2 line description and how to run the demo (open `index.html` or run a local server).
- If your demo is hosted (e.g., GitHub Pages), add a `Demo` link in that project's entry.
- Submit a Pull Request. In the PR description say what you added and where it appears.

Notes

- We prefer demos that anyone can open in a browser without installing packages.
- Keep filenames simple and avoid collisions with existing projects.

If you want me to add your project entry to the main `index.html` grid, include the demo link and a short description and I can do that for you.

Thanks! ✨
